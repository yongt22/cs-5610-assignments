Basic Structure

This page has a navigation bar, several sections, and a footer.

A list of the 10 most useful tags

  1. <header>: the top part of a page
  2. <nav>: a group of navigation links
  3. <main>: the main content of a page
  4. <section>: a section of related content
  5. <h1>: the main heading
  6. <h2>: a smaller heading
  7. <p>: a paragraph
  8. <ul>: an unordered list
  9. <li>: an item in a list
  10. <footer>: the bottom part of a page

SEO

SEO means Search Engine Optimization. It helps search engines understand the page.

The <head> stores page information. The <header> is visible on the page.

Useful SEO tags include:

  • <title>: the page title
  • <meta name="description">: a short page summary
  • <h1> to <h6>: the heading order
  • <link rel="canonical">: the main URL for the page
  • <meta name="robots">: tells search engines how to handle the page

I did not add meta keywords because Google does not use them.

Using a ad box as a creative part.

  • Static: the message stays in the normal layout.
  • Relative: the title moves a little from its normal spot.
  • Absolute: the label stays in the card's top-right corner.
  • Fixed: the card stays in the bottom-right corner of the screen.
